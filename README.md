# Музыкальный плеер для Obsidian

Плагин для управления музыкальной библиотекой в настольном Obsidian: локальные композиции, плейлисты, ссылки на YouTube и звуковые сигналы для действий в vault.

**Статус:** исходная реализация плагина подготовлена. Перед установкой соберите её командой `npm run build`.

## Задачи проекта

- Воспроизводить MP3, MPEG, WAV, Ogg/OGA/Opus, FLAC, AAC, CAF, M4A/M4B, аудио из MP4/WebM и E-AC-3, если этот формат поддерживает встроенный аудиодвижок Chromium.
- Добавлять аудиофайлы и папки в индекс без копирования, перемещения или изменения исходников.
- Создавать плейлисты из треков, найденных в одной или нескольких папках.
- Выбирать режим очереди: подряд, повтор всего списка или случайный трек.
- Объединять несколько плейлистов в коллекцию и временно исключать отдельные плейлисты из очереди, оставляя их видимыми.
- Сохранять ссылки на YouTube и воспроизводить видео через официальный встроенный плеер.
- Каждая новая ссылка добавляется в предустановленный плейлист YouTube. Ссылку можно также включить в другие плейлисты; удаление из плейлиста не удаляет саму ссылку.
- При ошибке YouTube предлагать переключение на последний проигрывавшийся локальный трек; дать отдельную настройку автоматического переключения.
- Дать панель управления с кнопками, громкостью, текущей композицией, перемоткой, временем трека и списком треков.
- Выбирать язык интерфейса: русский, украинский или английский.
- По желанию проигрывать выбранный звук при завершении задачи и других настраиваемых действиях.

## Принципы

- Удаление из библиотеки удаляет только запись индекса, но не исходный файл.
- Индексация выполняется при первом запуске библиотеки и вручную по команде пользователя.
- Ссылки YouTube хранятся как нормализованный ID видео, полученный из введённого полного URL.
- YouTube полностью выключен по умолчанию: первый запуск использует только локальные файлы; API и онлайн-интерфейс не загружаются до явного включения настройки.
- Плеер YouTube открывается нажатием на название трека, Play или значок глаза и остаётся видимым до явного закрытия пользователем. Закрытие ставит YouTube на паузу. Название ролика загружается из метаданных YouTube и сохраняется вместе со ссылкой.
- После добавления ссылки плагин запрашивает её название через YouTube; воспроизведение видео начинается только по действию пользователя.
- Автозапуск последнего трека и звуки действий выключены по умолчанию.
- Плагин рассчитан на Windows, macOS и Linux.
- При первой установке создать и один раз открыть в корне vault многоязычный Markdown-файл с руководством. Существующие файлы с таким именем не перезаписываются.

## Технические замечания

Аудио воспроизводится через встроенный HTML Audio; форматы в диалоге выбора отфильтровываются по возможностям Chromium. Локальные треки читаются из указанного пути и временно подаются в плеер через Blob URL; оригиналы не копируются и не перезаписываются. Звуки действий включают 21 синтезируемый пресет без системных файлов или загрузок и выбранные пользователем аудиофайлы. Нажатие на чекбокс завершения запускает звук сразу, а следующее событие изменения файла не воспроизводит дубликат.

В настройках плеера можно выбрать светлую, тёмную или тему Obsidian. Настройка палитры кнопок работает отдельно. При выключенной прокрутке название трека ограничено 40 символами; при включённой полный текст непрерывно проходит через строку. Нажатие на имя источника рядом с локальным треком показывает этот файл в проводнике.

В строке состояния Obsidian есть кнопка воспроизведения/паузы; её цвет следует выбранной палитре кнопок. В настройках плагина можно назначить сочетания клавиш для воспроизведения/паузы, следующего и предыдущего трека и открытия панели плеера. В разделе звуков действий доступно событие «Запуск Obsidian» с пятью короткими оригинальными мелодиями, а также пресет «Радостный визг мартышки». Звук запуска включается после добавления правила; если автозвук блокируется, он прозвучит при первом действии пользователя. Выбор звука в настройках сохраняет положение прокрутки.

Краткая [история версий и список регрессионных проверок](CHANGELOG.md) помогают отслеживать уже исправленные ошибки.

Нажмите на строку текущего трека, чтобы задать отображаемое имя. Оно сохраняется в индексе и не переименовывает файл на диске. При переиндексации папки плагин сохраняет связь с плейлистом для распознанных переименованных файлов.

Для YouTube используется официальный IFrame-плеер. Нажатие на название трека или Play показывает видео; плеер остаётся на месте до закрытия кнопкой. Значок возле названия текущего YouTube-трека показывает его повторно. При ошибке автоматический режим возвращается к последнему проигрывавшемуся локальному треку из текущей очереди.

Плагин desktop-only, поскольку выбор произвольных внешних папок использует файловый диалог ОС. Мобильные платформы не входят в целевой список.

## Сборка для разработки

1. Установите Node.js LTS.
2. Выполните `npm install` в этой папке.
3. Для разработки запустите `npm run dev`; для production-сборки — `npm run build`.
4. Скопируйте `main.js`, `styles.css` и `manifest.json` в `<vault>/.obsidian/plugins/music-library-player/`, затем включите Music Library Player в настройках Obsidian.

## Проверки

```sh
npm ci
npm test
npm run build
```

`npm run build` выполняет проверку TypeScript и создаёт production-файл `main.js`. `npm test` запускает тесты определения аудиоформатов, разбора YouTube URL, Markdown-чекбоксов и ручных правил.

## Установка и публикация

- **Из архива:** скачайте ZIP из GitHub Release и распакуйте `main.js`, `manifest.json` и `styles.css` в `<vault>/.obsidian/plugins/music-library-player/`. В Obsidian включите плагин в **Настройки → Сторонние плагины**.
- **Из Git для личного тестирования:** установите BRAT в Obsidian и добавьте адрес публичного GitHub-репозитория.
- **В каталоге плагинов Obsidian:** сначала опубликуйте исходники в публичном GitHub-репозитории и Release с тегом, совпадающим с `version` в `manifest.json`; приложите к Release `main.js`, `manifest.json` и `styles.css`. Затем отправьте плагин через [каталог сообщества Obsidian](https://community.obsidian.md). До принятия заявки он не будет отображаться в поиске Community plugins.

Перед публикацией замените имя автора в `manifest.json` и заголовок лицензии `LICENSE`, если хотите указать своё имя или иной тип лицензии. GitHub Actions проверит тег, запустит тесты и сборку, затем опубликует Release с файлами плагина и ZIP-архивом.

Для запуска релиза создайте тег, точно совпадающий с версией в `manifest.json` (например, `0.1.14`, без префикса `v`), и отправьте его в GitHub: `git tag 0.1.14` и `git push origin 0.1.14`. После завершения GitHub Actions проверьте опубликованный Release.
