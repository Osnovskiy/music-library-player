# Music Library Player — музыкальный плеер для Obsidian

**Music Library Player** — плагин для настольного Obsidian, который превращает боковую панель в музыкальный плеер. Он индексирует композиции из хранилища Obsidian или внешних папок, помогает собирать плейлисты и управляет воспроизведением, не перемещая и не переписывая исходные файлы.

**Текущая версия: 0.1.14.** Плагин рассчитан на Obsidian Desktop для Windows, macOS и Linux. Интерфейс доступен на русском, украинском и английском языках.

## Возможности

- Воспроизведение аудиофайлов, поддерживаемых встроенным аудиодвижком Obsidian/Chromium: MP3, MPEG, WAV, Ogg, OGA, Opus, FLAC, AAC, CAF, M4A/M4B и некоторых других форматов. Доступность формата зависит от системы и кодеков.
- Добавление отдельных файлов и целых папок из vault или с диска. Плагин хранит ссылки на файлы и не копирует, не перемещает и не переименовывает их.
- Индекс библиотеки и ручное обновление источников. Удаление трека из списка удаляет только запись плагина.
- Плейлисты и коллекции из нескольких плейлистов. Можно временно исключать плейлисты из очереди, сворачивать их отображение и выбирать последовательное, циклическое или случайное воспроизведение.
- Управление из боковой панели и строки состояния: воспроизведение/пауза, предыдущий и следующий трек, громкость, перемотка, длительность и список композиций.
- Светлая, тёмная и тема Obsidian, несколько палитр кнопок, прокрутка длинного названия трека и горячие клавиши.
- Дополнительные звуки для завершения задач, запуска Obsidian и других событий. Можно выбрать встроенный сигнал или собственный аудиофайл.
- YouTube выключен по умолчанию. При включении ссылки добавляются в отдельный плейлист YouTube и запускаются во встроенном официальном плеере по действию пользователя. При ошибке можно вернуться к последнему локальному треку; автоматическое переключение настраивается отдельно.

## Установка

### Из GitHub Release

1. Откройте [Releases](https://github.com/Osnovskiy/music-library-player/releases) и скачайте ZIP последней версии.
2. Распакуйте `main.js`, `manifest.json` и `styles.css` в папку `<путь-к-vault>/.obsidian/plugins/music-library-player/`. Создайте папку, если её ещё нет.
3. В Obsidian откройте **Настройки → Сторонние плагины**, включите сторонние плагины и активируйте **Music Library Player**. Если плагин не появился, перезапустите Obsidian или выполните перезагрузку приложения.

### Через BRAT

Установите BRAT из каталога плагинов Obsidian, добавьте репозиторий `Osnovskiy/music-library-player` в список Beta-плагинов и включите Music Library Player в разделе сторонних плагинов.

## Начало работы

1. Откройте Music Library Player в боковой панели Obsidian. При первом запуске в корне vault появится краткая инструкция на выбранном языке.
2. В настройках плагина выберите источники музыки: папку внутри vault или внешнюю папку на диске. Также можно добавить отдельный файл. Исходные композиции останутся на своих местах.
3. Запустите индексацию источников. После этого треки появятся в разделе коллекции.
4. Создайте плейлист и добавьте в него отдельные треки или всю папку. Несколько плейлистов можно объединить в коллекцию.
5. Выберите плейлист или коллекцию в панели и нажмите **Play**. Используйте строку прогресса для перемотки. Нажмите на название текущего трека, чтобы открыть его полное имя или переименовать отображаемую запись.
6. По желанию настройте горячие клавиши, тему, палитру кнопок и звуки действий в настройках плагина.

## YouTube

YouTube требуется включить в настройках: пока эта опция выключена, плеер работает только с локальными файлами. Вставьте полный адрес ролика — плагин извлечёт идентификатор, получит название и добавит композицию в плейлист **YouTube**. Воспроизведение запускается нажатием на название трека, кнопку Play или значок просмотра. Видео отображается во встроенном плеере, который можно закрыть вручную.

YouTube может запрещать воспроизведение отдельных роликов или ограничивать фоновое воспроизведение. Включите автоматический возврат к последнему локальному треку в настройках, если хотите, чтобы при ошибке плеер переключался на музыку из текущей очереди.

## Обновление и данные

Для обновления скачайте ZIP новой версии и замените в папке плагина `main.js`, `manifest.json` и `styles.css`. Настройки и индекс хранятся в vault Obsidian. Переиндексация находит новые и переименованные файлы; удаление из библиотеки не затрагивает файл на диске.

## Разработка

Нужен Node.js LTS. Из папки проекта выполните:

```sh
npm ci
npm test
npm run build
```

Production-сборка создаёт `main.js`. Для установки собранной версии скопируйте `main.js`, `manifest.json` и `styles.css` в папку плагина внутри vault. GitHub Actions запускает тесты и сборку при отправке тега, совпадающего с версией в `manifest.json`, и публикует ZIP с файлами плагина.
